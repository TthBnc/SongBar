# SongBar 0.1.2

## What's new

- Added optional Spotify login from Settings using your own Spotify Developer Client ID.
- Added a heart button in the panel to save or remove the current track from Spotify Liked Songs.
- Added a custom Spotify OAuth callback page so login no longer lands on a blank white browser page.
- Improved the panel metadata with clearer song, artist, and album icons.
- Kept base now-playing, playback control, open, copy, and share features available without Spotify login.

## Notes

- Liked Songs requires Spotify Web API access. Create a Spotify Developer app, add `http://127.0.0.1:17654/callback` as a redirect URI, select Web API, and paste the app's Client ID into SongBar Settings.
- Use `127.0.0.1`, not `localhost`, for the redirect URI. Spotify development-mode apps support up to 5 allowlisted users.
- This build is still unsigned. On first launch, right-click SongBar in Applications and choose Open.
